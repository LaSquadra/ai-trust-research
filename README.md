# AI Trust Research: From Authority to Action

An independent evidence synthesis on governing consequential AI-agent actions through scoped authority, receiver-side enforcement and outcome evidence.

## Main conclusion

Bind current task authority to the actual principal, execution route, receiving service and permitted effect. Enforce locally. Additional independent reconciliation must demonstrate value beyond simpler receiver-local controls.

## Status and limits

Evidence-synthesis phase concluded November 13, 2026. No project experiments have run. Necessity, sufficiency, minimality and security improvement remain unproven. This is a research companion, not a supported product or a commitment to continuing updates.

This is personal independent research, not an employer-endorsed product. Established security principles are credited as foundations; the contribution is their traceable synthesis and a falsifiable evaluation plan.
